# Material Question Helper

Ask only when the answer changes at least one of: scope boundary, externally visible behavior, architecture direction, acceptance proof, sequencing, or a non-negotiable constraint.

Rank candidate gaps by downstream rework risk, then ask the highest-ranked one. Prefer a concise open question when the answer space is unknown. Offer 2–3 mutually exclusive interpretations only when evidence already narrows the real choices. Recommend one only when the evidence supports it and state the tradeoff.

Never ask for information already present in the conversation, references, or inspected project evidence. Never ask administrative questions such as preferred file names before product sufficiency.

When an answer is vague, reflect one concrete interpretation and ask for confirmation. If it remains unresolved and is material, label the artifact blocked. If it is non-material, record it as a follow-up with its limited impact.

Before asking, state in one sentence why the answer changes the artifact. Ask one question, then stop.
